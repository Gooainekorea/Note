"아래것들의 개념을 전문용어로 간지나게 표현해줘"

1. 프로세서 (Processor)
단순한 '연산 처리 하드웨어'라는 표현 대신, 시스템의 두뇌로서의 역할을 강조하는 것이 전문적입니다.

전문적 정의: 명령어 집합 아키텍처(ISA)를 기반으로 데이터 경로와 제어 유닛을 통해 연산 및 로직을 수행하는 중앙 처리 장치(Central Processing Unit) 또는 연산 로직 유닛(ALU)을 포함한 핵심 제어 모듈입니다.

교수 관점 코멘트: "단순히 계산만 하는 것이 아니라, 레지스터와 버스 인터페이스를 제어하며 전체 시스템의 동기화를 책임지는 주체입니다."

2. 프로세스 (Process)
'프로그램이 실행되는 상태'라는 점을 명확히 하고, 자원 할당의 단위임을 강조해야 합니다.

전문적 정의: 보조 기억 장치에 저장된 정적인 프로그램이 메모리 공간에 로드되어, 커널에 의해 프로세스 제어 블록(PCB)을 할당받고 생명 주기를 갖게 된 **실행 중인 작업 단위(Active Program Instance)**입니다.교수 관점 코멘트: "코드(Code), 데이터(Data), 힙(Heap), 스택(Stack)의 메모리 영역을 독립적으로 점유하며 스케줄링의 대상이 되는 동적인 객체라고 표현해야 정확합니다."

3. 인터프리터 (Interpreter)
'한 줄 단위 실행'을 넘어 런타임 환경에서의 동작 방식을 설명해야 간지납니다.

전문적 정의: 소스 코드를 목적 파일로 변환하는 선행 컴파일 과정 없이, 런타임 환경에서 **구문 분석(Parsing)과 실행(Execution)을 즉시 수행하는 언어 번역기 및 가상 머신(Virtual Machine)**입니다.

교수 관점 코멘트: "Read-Eval-Print Loop(REPL) 구조를 가지며, 플랫폼 독립성을 보장하지만 JIT(Just-In-Time) 컴파일러 없이는 네이티브 코드 대비 오버헤드가 발생할 수 있다는 점을 명심하십시오."

4. 인터럽트 (Interrupt)
'최고 우선순위 할 일'이라는 표현은 너무 추상적입니다. 하드웨어적 신호와 흐름 제어 변경을 언급해야 합니다.

전문적 정의: 프로세서가 현재 수행 중인 명령어 사이클을 일시 중단하고, 비동기적으로 발생한 예외 상황이나 외부 이벤트에 대응하기 위해 인터럽트 서비스 루틴(ISR)으로 제어 흐름을 즉시 전환시키는 하드웨어/소프트웨어 메커니즘입니다.

교수 관점 코멘트: "단순한 우선순위 처리가 아니라, 문맥 교환(Context Switch) 비용을 감수하고서라도 즉각적인 응답성을 보장해야 하는 리얼타임 시스템(RTOS)의 핵심 요소입니다."
