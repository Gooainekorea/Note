- STM32
	-DSP/SIMD/MAC
	- A,R,M의 차이 
	- M의 개념
SVE2: 고급 벡터 처리 명령어 셋 아키텍처(ISA) 확장
SME2: 행렬곱 처리확장

SIMD: 하나의 명령어로 여러 개의 데이터를 한꺼번에 처리하는 기술
SRAM: Static Random Access Memory S램
DSP: 디지털 신호 처리 장치-수학연산특화
FPU: 부동소수점연산기

특징	Cortex-M3 (예: STM32F1, F2)	Cortex-M4 (예: STM32F3, F4, L4)
FPU (부동 소수점 연산기)	없음 (소프트웨어 처리)	하드웨어 FPU 탑재 (싱글 프리시전)
DSP 명령어	없음	DSP 전용 명령어 지원 (SIMD, MAC 등)
아키텍처	ARMv7-M	ARMv7E-M (연산 기능 확장형)
주요 용도	일반적인 제어, 단순 I/O 처리	복잡한 수학 계산, 오디오/영상 처리, 센서 퓨전
