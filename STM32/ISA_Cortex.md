Armv: ARM 아키텍처 주요 버전
    RISC기반의 프로세서 아키텍처

RISC(Reduced Instruction Set Compute) 
- ALU는 단순한 연산만 수행, 레지스터간에서 대부분 연산처리
- 많은 수의 범용 레지스터를 제공하여, 메모리 접근을 줄이고 연산 속도 높임.
- 명령어는 레지스터 간 연산만 허용하며, 메모리 접근은 로드/스토어 명령으로만 제한.
    - 메모리 접근을 명령어로 수행. 병렬처리용이
    - 명령어 세트로 실행됨, 단순한 고정길이
    - 연산은 레지스터 간에만 수행. 실행 속도 빠름
    - 하드웨어 단순, 저전력

CISC(Complex Instruction Set Computer)
- ALU는 복잡한 연산도 처리가능하며 메모리 직접 접근이 가능
- 레지스터 수가 상대적으로 적음, 명령어가 메모리 직접연산 가능 
    - 명령어 세트로 실행됨, 단순한 고정길이
    - 메모리 직접 접근, 명령어길이 가변적
    - 하나의 명령어가 여러 단계의 마이크로 코드로 처리
    - 하드웨어 복잡, 고전력

Cortex-A
    복잡한 OS돌리는 장치, 고성능
    사용처: 스마트폰, PC
    - MMU(가상메모리 지)
Cortex-R
    실시간 정밀제어용, 응답속도가 일정하고 빠름
    사용처: 자율주행, 의료
    - MPU
Cortex-M
    저전력, 가성비, 펌웨어용
    사용처: 가전제품, 센서
    - MPU
